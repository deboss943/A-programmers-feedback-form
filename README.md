Programmers Feedback Survey

A simple Programmers Feedback Survey Form built with HTML. This project collects basic information from programmers, including their name, email, age, programming experience, preferred programming language, technologies of interest, and additional comments.

Features
Name input field
Email input field with email validation
Age input with minimum and maximum values
Programming experience level dropdown
Multiple programming language options
Radio buttons for selecting a programming language
Checkboxes for selecting technologies of interest
Additional comments textarea
Submit button
Required fields for name and email
